# journal-tracker

Два независимых продукта в одном репозитории:

- **`index.html`** — личный трекер-журнал (PWA, задачи/идеи/заметки, встроенный Claude-агент). Плюс `sw.js`, `manifest.json`, `icon.svg`.
- **`teleprompter.html`** — автономный телесуфлёр для записи видео в блог (Инстаграм). Один самодостаточный файл, ни от чего не зависит. Не связывать его с трекером — владелец просил держать их раздельно.

Сайт публикуется на GitHub Pages **автоматически при каждом пуше в `main`** (workflow `.github/workflows/pages.yml`, публикация занимает ~минуту):

- Суфлёр (личная версия владельца): https://aleksandr1304.github.io/journal-tracker/teleprompter.html
- Суфлёр (публичная версия для раздачи людям): https://aleksandr1304.github.io/journal-tracker/prompter.html

`prompter.html` **генерируется на публикации** из `teleprompter.html`: workflow вырезает участки между метками `<!-- PERSONAL:START/END -->` (HTML) и `/* PERSONAL:START/END */` (JS) — это автоподгрузка личного сценария из `script.json`. В git `prompter.html` не кладётся (есть в `.gitignore`). Правки функций суфлёра делай в `teleprompter.html`; личные для владельца вещи оборачивай метками PERSONAL, чтобы они не попадали в публичную версию.

## Суфлёр: как отправить текст («отправь текст в суфлёр»)

Когда владелец просит отправить/загрузить текст (сценарий ролика) в суфлёр:

1. Запиши текст в **`script.json`** в корне репозитория:

   ```json
   {
     "title": "Короткое название ролика",
     "text": "Полный текст сценария. Абзацы разделяй \\n\\n.",
     "updatedAt": "<текущий момент, ISO 8601 UTC, например 2026-08-10T12:00:00Z>"
   }
   ```

   `updatedAt` обязан отличаться от прежнего значения — именно по нему страница понимает, что текст новый, и подхватывает его.

2. Доведи изменение до `main` и убедись, что оно там оказалось. Владелец одобрил прямой пуш `script.json` в `main` без ревью; если правила сессии требуют работать через ветку — сделай ветку, открой PR и сразу же сам его смержи (squash), владельца дёргать не нужно.

3. Публикация на Pages произойдёт сама за ~минуту. Владельцу достаточно открыть страницу суфлёра — текст подхватится автоматически (сравнение по `updatedAt`).

Текст пиши как для чтения вслух: короткие фразы, без markdown-разметки, абзацы через пустую строку.

## Суфлёр: записанные видео в Telegram

После записи владелец отправляет ролик кнопкой «Отправить в Telegram» своему личному боту
(токен и chat id хранятся только в localStorage его устройства). Когда владелец просит
«проверь ролики / забери видео из бота»:

- Токен бота ищи в переменной окружения `TELEGRAM_BOT_TOKEN` (владелец добавляет её в
  настройках окружения Claude Code). **Токен никогда не коммитить и не печатать в логах/чате.**
- `POST https://api.telegram.org/bot<TOKEN>/getUpdates` — список сообщений; у видео смотри
  `message.video` (caption, duration, file_size, date, file_id).
- Файл можно скачать через `getFile` + `https://api.telegram.org/file/bot<TOKEN>/<file_path>` —
  но только до 20 МБ (лимит Telegram для ботов). Ролики крупнее — работать по метаданным.
- Скачанные видео в git не класть.
- Если api.telegram.org недоступен из песочницы — это сетевая политика окружения; попроси
  владельца разрешить домен в настройках окружения, сам ничего не обходи.

## Правки кода

Изменения кода (не `script.json`) — через ветку и PR, как обычно. Файлы трекера (`index.html`, `sw.js`, `manifest.json`) не трогать при работе над суфлёром.
